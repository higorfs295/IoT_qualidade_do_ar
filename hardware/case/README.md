# Case do protótipo

Esta pasta contém os parâmetros e o roteiro de criação do invólucro. Os arquivos
SolidWorks/STL ainda dependem das dimensões da PCB Rev A e dos módulos físicos;
por isso não são apresentados como artefatos prontos.

- Roteiro completo: [`../../docs/ROADMAP_CASE_SOLIDWORKS.md`](../../docs/ROADMAP_CASE_SOLIDWORKS.md)
- Parâmetros a medir: [`parametros.csv`](parametros.csv)
- Plano de aceite: [`../../docs/PLANO_TESTES.md`](../../docs/PLANO_TESTES.md)

Ordem correta: congelar PCB/conectores -> medir montagem -> modelar skeleton ->
base/tampa/duto -> interferência -> cupons -> impressão -> ensaio térmico/fluxo.
